# Amanatsu AI Chat — ユーザーマニュアル

対象: Amanatsu AI Chat 0.7.3。これは非公式Modです。通常のゲームはタイトル画面から従来どおり遊べます。会話画面へは、タイトルの「Amanatsu AI Chat v0.7.3」から入ります。

英語で会話したい場合は、英語版の配布ZIP（`AmanatsuAiChat-EN-0.7.3.zip`）を使ってください。画面・AIへの指示・性格プリセットがすべて英語になり、キャラも英語で話します。

このファイルは利用者向けです。実装・検証・AIエージェント向けの情報は、別添の `README-AI.md` を参照してください。

## 1. 必要なもの

- 『甘夏ろけーしょん』と BepInEx 6。使うのは「Unity IL2CPP」用の「Windows x64」版で、BepInEx 5系やMono版では動きません。動作を確認した環境は、ゲーム 1.0.2 / BepInEx 6.0.0-be.788 です。
- Windows と Python 3.10 以降。`python --version` で確認できます。PythonはゲームとAIの間の通信を取り持つ「ブリッジ」を動かすために使います。プログラムを書く必要はなく、導入時に書いてあるコマンドを実行するだけです。
  - python.org のインストーラーを使う場合は、最初の画面で「Add python.exe to PATH」にチェックを入れてください。入れ忘れると `python` コマンドが通りません。
  - `python` と打ってMicrosoft Storeが開く場合は、Pythonが入っていないか、PATHが通っていません。インストールし直してください。
- Ollama、またはOpenAI互換のチャットAPI。OllamaはPC上でAIモデルを動かすソフトで、公式サイト（ollama.com）のインストーラーで入れられます。初期設定では、Ollamaと公式の `gemma4:e4b` を使います。公式のモデルは性的な頼みや服を脱ぐ頼みを断ることがあるので、そうした会話もしたい場合は、無規制版（Uncensored）のモデルの導入をおすすめします。モデル本体はModに含まれず、Ollamaで別にダウンロードします。利用するモデルの配布条件は、ご自身で確認してください。
- 会話に使う女性キャラカード（PNG）。カードはModに含みません。

ゲーム本体、キャラカード、モデル、APIキー、フォント、他のModは、配布ZIPに含まれません。

### 動作の重さについて

ローカルモデルは重い処理です。ゲームとGPUを共有するため、RTX 3060 Laptop（GPUメモリ6GB）では、1回の返事に1分近くかかることがあります。GPUメモリが少ない場合は、小さいモデルを選んでください。GPUの性能が足りない場合は、OpenAIなどのAPIを使う方法もあります（有料）。

モデルのダウンロードサイズの例です。GPUメモリより大きいモデルは一部がCPUで動くため、さらに遅くなります。

| モデル | サイズ |
| --- | --- |
| `gemma4:e4b`（初期設定） | 約9.6GB |
| Qwen3 8B（Q4_K_M） | 約5.0GB |
| Gemma 4 E4B（Q4_K_M） | 約6.3GB |

## 2. 導入

以下のコマンド例では、ゲームの場所を `C:\ILLGAMES\AmanatsuLocation` としています。別の場所に入れている場合は読み替えてください。

1. ゲームを終了します。起動中のDLLは上書きできません。
2. 配布ZIPを展開し、展開先の `AmanatsuAiChat-0.7.3` フォルダーを開きます。
3. そのフォルダーでPowerShellを開き、`python -m pip install -r .\BepInEx\plugins\AmanatsuAiChat\requirements.txt` を実行します。
4. 同じ場所で `./install.ps1 -GameRoot 'C:\ILLGAMES\AmanatsuLocation'` を実行します。
   - 以前の版が `BepInEx/plugins` の下のフォルダー（例: `plugins/SELF`）にあれば、その場所を更新します。なければ `BepInEx/plugins` に入れます。
   - 置き換えたファイルは、ゲーム側の `BepInEx/config/amanatsu.ai-chat/backups` に退避します。設定・カード・セーブは上書きしません。
   - `Amanatsu.AiChat.dll` が複数の場所にあると二重に読み込まれるため、インストーラーは中止して場所を表示します。1つだけ残してからやり直してください。
5. Ollamaを使う場合は、Ollamaを起動してモデルを導入します。初期モデルの場合: `ollama pull gemma4:e4b`。大容量なので、空き容量と時間に注意してください。
6. ゲームを起動します。タイトルに「Amanatsu AI Chat v0.7.3」が表示されれば、Modは読み込まれています。

`install.ps1` が実行ポリシーで拒否された場合は、PowerShellのエラーメッセージを確認し、信頼できる配布物に限って一時的な実行許可を使ってください。セキュリティ設定を恒久的に緩める必要はありません。

## 3. 最初の会話

1. タイトル画面の「Amanatsu AI Chat v0.7.3」を押します。初回はキャラカードの選択ダイアログが開くので、会話するPNGカードを選びます。キャンセルするとタイトルのままです。選んだカードは記憶され、次回からはそのカードで開きます。
2. キャラとピンク色のセリフ枠が表示されたら、左側の「接続設定」を開きます。
3. 接続方式とLLM API URLを確認し、モデル名の横の「一覧から選ぶ…」で、導入済みのモデルを選びます。選んだら「保存して適用」を押します。Ollamaをローカルで使うなら、通常APIキーは要りません。
4. 「ブリッジ再起動」を10秒以内に2回押し、「再起動完了」と表示されるまで待ちます。これは、このMod用のローカルブリッジだけを起動し直す操作です。ブリッジがまだ動いていないときは、そのまま起動します。
5. 「接続確認」を押します。ブリッジの応答と、指定したモデルが導入されているかを確認します。モデルに文章を生成させる確認ではないので、最後に短い会話を1回試してください。

会話画面を開いたときとキャラを切り替えたときは、キャラのほうから最初のひと言を話しかけます。挨拶の生成中にメッセージを送ると、挨拶を取りやめてそちらに返事をします。

返答の速さは、モデルの大きさとPCの性能で大きく変わります。GPUのないPCでは数分かかることもあります。応答中は「中止」で取り消せます。会話を終えるときは、左パネルの「終了」を押すと通常のタイトルへ戻ります。

## 4. 画面と操作

| 操作 | 内容 |
| --- | --- |
| タイトルの「Amanatsu AI Chat v0.7.3」 | 会話画面へ移動します。通常ゲームの開始ボタンはそのまま残ります。 |
| 「前のキャラ」「次のキャラ」 | `UserData/chara/female` のカードを順に切り替えます。 |
| 「ファイルから選択…」 | WindowsのダイアログでPNGカードを選びます。パスを手入力する必要はありません。 |
| キャラ名の横の「◀ ポーズ ▶」 | 待機中の立ち方（ポーズ01〜12）を切り替えます。選んだポーズはキャラごとに保存され、モーションのあとも同じポーズに戻ります。 |
| 「衣装: 水着／風呂上がり」 | 水着と風呂上がりのコーデを切り替えます。脱いだ・半脱ぎの状態は部位ごとに引き継ぎます。着替え先にない部位は着たままです。 |
| 「顔」「胸元」「全身」 | カメラの構図を切り替えます。ホイールでズームできます。 |
| Shiftを押しながら左ドラッグ | 視点を回します。右または中ドラッグで平行移動します。 |
| Ctrl | 初期の構図に戻します。 |
| 1 / 2 | 視線・首を、カメラに向けるかアニメーションに任せるかで切り替えます。 |
| 眉・目・口の `+` / `-` | 表情のパーツを個別に変えます。 |
| 「赤面」「目の開き」「口の開き」 | `+` / `-` で強さや開き具合（0.0〜1.0）を固定します。目と口は「自動」で瞬き・口の動きに戻ります。 |
| 表情プリセットの欄（「前」「次」「新規」「現在の表情を保存」「削除」） | 全キャラ共通の表情プリセットを作成・編集・削除します。使い方は5章の「表情プリセットの作成・編集・削除」を参照してください。 |
| 「ライト」 | キャラ用ライトの縦・横の向き、強さ、色（Windowsの色選択）を調整します。「初期値に戻す」もあります。設定は保存されます。 |
| 「影」 | 会話画面のライトの影を、なし・ハード・ソフトで切り替えます。 |
| 「環境設定」 | ゲーム本来のオプション画面を開きます。閉じると会話に戻ります。 |
| 「背景」の「前」「次」／「画像を選択…」 | 単色、ゲーム同梱の背景画像、または手持ちのPNG/JPEGを背景にします。画像ファイル自体はModへコピーしません。 |
| 右上の「－」／左上の「メニュー」／H | 操作パネルを隠したり、表示し直したりします。 |
| 「終了」 | 会話を終えて、通常のタイトルへ戻ります。 |
| セリフ枠をクリック／スペース／PageDown | 長い返事はページに分けて表示し、続きがあるときは末尾に「▼」が付きます。セリフ枠をクリックするか、スペースキーかPageDownを押すと次のページを表示します。キーは文字入力欄にカーソルがない間だけ働きます。 |

キー割当は設定ファイルで変えられます。文字入力欄にカーソルがある間は、1・2・H・Ctrlなどのショートカットは働きません。F10でも会話画面を開閉できます。

### AIが動かせるもの

AIは返事のたびに、会話の流れに合わせて次のものを選びます。

- **表情**: 全キャラ共通の表情プリセット（初期状態で29種類）から選びます。眉・目・口を個別に組み合わせることはしません。
- **モーション**: 伸び、ストレッチ、遠くを見るなどの動きを選びます。「左右へ振り向く」は、正面を向いた会話画面では背中を向けたままになるため、選択肢に入れていません。
- **立ちポーズ**: 12種類から、気分や「腕を組んで」などの頼みに合わせて選びます。選んだポーズは返事のあとも続き、キャラごとに保存されます。
- **服装**: 下の「服装への頼み方」を参照してください。

### 服装への頼み方

「脱いで」「上だけ脱いでよ」「ブラとショーツを着て」「全裸になって」「お尻見せて」など、言い方は自由です。AIが頼みを読み取り、キャラが応じたときだけ着替えます。断られたときは変わりません。

- AIには、今どの部位を着ているかと、その衣装の名前（例: フリルビキニ）を毎回伝えています。そのため「水着を脱いで」のような頼み方も通じます。
- 「着衣」「ブラ見せ」「パンツ見せ」「下着姿」「トップレス」「ボトムレス」「全裸」のようなまとまった状態も選べます。このうち脱ぐ方向の状態は脱がせるだけで、すでに脱いでいる部位を着せ直すことはありません。全部を着せ直すのは「着衣」だけです。
- 今の服装で変えようのない選択肢（上着がないのに「ブラ見せ」など）は、AIに見せません。
- 変わるのは表示中の衣装の状態だけです。カード画像や衣装データは書き換えません。会話を終えたり、キャラを変えたりすると、元の服装に戻ります。

### 会話の記憶

会話の内容は、ゲームを起動している間だけ覚えています。会話画面を閉じて同じキャラで開き直した場合は続きから話せますが、キャラを切り替えたときと、ゲームを終了したときには忘れます。保存はしません。長い会話では、モデルが扱える量に合わせて古いやり取りから省きます。どこまで渡すかは「接続設定」の「詳細設定…」で変えられます。

## 5. 性格・表情・接続の設定

「性格・口調を編集」では、キャラの話し方・性格・相手への接し方を編集します。「カードへ適用」を押すと、そのカードに対応するMod側の設定に保存します。カードPNGそのものは書き換えません。「別名で保存…」で性格だけを別ファイルに保存でき、「ファイルを開く…」で読み込めます。読み込んだあとは「カードへ適用」を押してください。出力の形式やモーションの制御は、この欄では変えられません。

配布物には、世話好き・僕っ子・清楚・お嬢様・しっかり者・ギャル・姉御肌・健気・大人しい・ツンデレの10種類の性格プリセットが入っています。インストール時に `BepInEx/config/amanatsu.ai-chat/personalities` へコピーされるので、「ファイルを開く…」で選んでから「カードへ適用」を押してください。同じ名前のファイルがすでにある場合は上書きしません。

### 表情プリセットの作成・編集・削除

AIが選ぶ表情は、全キャラ共通の「表情プリセット」です。初期状態で29種類あり、操作パネルの下の方にある表情の欄で、作成・編集・削除ができます。AIには、各プリセットのIDと説明が渡ります。AIは説明を読んで表情を選ぶので、説明は「どんな場面で使う顔か」が分かるように書くのがコツです。

**新しく作る**
1. 表情の欄の「新規」を押します。IDと説明の欄が空になります。
2. 操作パネルで顔を作ります。眉・目・口は `+` / `-` で形を選び、「赤面」「目の開き」「口の開き」は `+` / `-` で強さを決めます。目と口を「自動」にしておくと、瞬きや口の動きはアニメーションに任せます。
3. ID（小文字の英字で始まり、小文字英数字と `_` で40文字まで）と、AIに見せる説明（改行なしで160文字まで）を入れます。
4. 「現在の表情を保存」を押します。

**今ある表情を直す**
1. 表情の欄の「前」「次」で、直したい表情を選びます。選ぶとその顔が表示され、IDと説明も欄に入ります。
2. 顔や説明を直します。
3. IDはそのままで「現在の表情を保存」を押すと、上書きされます。IDを変えて保存すると、元の表情は残ったまま、別の表情として増えます。

**削除する**
1. 「前」「次」で、消したい表情を選びます。
2. 「削除」を押し、10秒以内にもう一度押します。1回目の後は確認のメッセージが出ます。
3. 最後の1つは削除できません。初期の29種類も削除できますが、元に戻す機能はないので注意してください。

保存先は、全キャラ共通の `BepInEx/config/amanatsu.ai-chat/expression-presets.json` です。作成・編集・削除は、次の返事から反映します。赤面の見え方は、キャラ側の素材や設定によって変わります。

「接続設定」では、接続方式（Ollama／OpenAI互換API）、ブリッジURL、LLM API URL、モデル名、APIキー、Ollamaの思考のログ記録を変えられます。モデル名は「一覧から選ぶ…」で選ぶと、打ち間違いを防げます。一覧は入力中のAPIキーで取得するので、保存前でも使えます。件数が多いときは「前のページ」「次のページ」で送ります。OpenAI互換APIの一覧からは、音声・画像・埋め込み用など会話に使えないモデルを除いています。リモートのAPIにはHTTPSが必要です。思考のログをONにすると、モデルの思考文がログに残ることがあるので、プライベートな会話ではOFFをおすすめします。

### LLM API URL の調べ方（Ollama）

Ollamaを同じPCで使う場合、LLM API URLは初期値の `http://127.0.0.1:11434/api/chat` のままで使えます。

- Ollamaが起動しているかは、ブラウザで `http://127.0.0.1:11434` を開くと確かめられます。「Ollama is running」と表示されれば起動しています。
- 環境変数 `OLLAMA_HOST` でポート番号を変えている場合は、`11434` の部分をその番号に合わせてください。
- 別のPCで動いているOllamaにつなぐ場合は、`https://` で始まるURLが必要です。
- URLを入れたら「一覧から選ぶ…」を押してください。導入済みのモデルが一覧に出れば、URLは正しく設定できています。

OpenAIのAPIを使う場合は、接続方式を「OpenAI互換API」にし、LLM API URLに `https://api.openai.com/v1/chat/completions` を入れて、APIキーを入力してください。新しい世代のモデルが `max_tokens` や `temperature` を受け付けない場合は、ブリッジが自動で送り方を切り替えます。API利用料はOpenAIのアカウントに請求されます。

「接続設定」の「詳細設定…」では、返事の上限、文脈の長さ、モデルに渡す会話履歴の件数を変えられます。通常は変える必要はありません。空欄のままなら初期値（返事512トークン、文脈はOllama 4096／API 16384トークン、履歴30件＝15往復）を使います。会話をどこまで覚えているかは、ほぼ文脈の長さで決まります。Ollamaで大きくすると、覚えている量は増えますが、GPUメモリを多く使って遅くなります。変えたら「保存して適用」と「ブリッジ再起動」を押してください。

思考（thinking）するモデルは、返事が遅くなったり、途中で切れたりすることがあります。Gemma 4 系やQwen3 系などを使うときは、思考しない設定のモデルを選んでください。途中で切れたときは、ブリッジが上限を広げて1回だけやり直します。

設定の正本は、ゲーム側の `BepInEx/config/amanatsu.ai-chat.cfg` です。接続設定は `BepInEx/config/amanatsu.ai-chat/bridge.json` にも写されます。設定ファイルを手で直すときは、ゲームを終了してから編集してください。起動中に編集すると、ゲームの保存で上書きされます。APIキーやトークンは平文で保存されるので、設定やログを他人に渡す前に確認してください。

主な手動設定:

| 設定 | 用途 |
| --- | --- |
| `[UI] Language` | 初期値は `auto` で、導入した版（日本語版・英語版）に合わせます。`ja` か `en` にすると、その言語に固定します。 |
| `[UI] OpenOnStartup` | 初期値は `false` です。`true` にすると、起動直後に会話画面を開きます。 |
| `[Character] CardPath` | 最後に選んだカードです。空にすると、次回は選択ダイアログが開きます。 |
| `[Appearance] BackgroundImage` | `none`、`game:0`〜`game:9`、またはPNG/JPEGの絶対パスを指定します。画像は32MB以下、縦横8192px以下です。 |
| `[Appearance] JapaneseFontFile` / `InputFontSize` / `InputBackgroundOpacity` | 入力欄の文字のフォント・大きさ・背景の濃さを変えます。 |
| `[Camera] DefaultPreset` / `SmoothingSeconds` / `FieldOfView` | 初期の構図、カメラの追従の速さ、画角を変えます。 |
| `[Keybinds]` | F10、1、2、H、Shift、Ctrl、マウスボタンの割当を変えます。 |
| `[Graphics] FollowGameSettings` | 初期値は `true` で、会話を始めるたびにゲームの描画設定を取り込みます。`false` にすると、Mod側に保存した値を使います。 |
| `[Graphics]` の他の項目 | 会話時の影の種類、ブルーム、被写界深度、ビネットなどです。ゲームの「環境設定」で変えると、会話画面にも反映します。 |
| `[Light]` | キャラ用ライトの向き・強さ・色です。通常は「ライト」パネルから変えてください。 |
| `[Bridge]` | 接続先、モデル、認証、思考のログ、詳細設定（`MaxReplyTokens`・`ContextTokens`・`HistoryMessages`）です。通常はゲーム内の「接続設定」から変えてください。 |

会話画面は、本編のマップと同じ仕上げ（トーンマップ・色調・シャープ・ブルーム・被写界深度など）で描画し、ゲームの「環境設定」のブルーム・被写界深度・ビネット・SSAO・アンチエイリアスを反映します。キャラ用ライトは本編と同じくカメラに付いて動き、影はソフトシャドウです。霧・マップ・シールドの設定は、人物と背景画像だけの会話画面では変化が見えません。背景画像にも色調とブルームが掛かるので、明るい画像は白っぽく見えることがあります。

## 6. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| タイトルにボタンがない | BepInExが入っているか、`Amanatsu.AiChat.dll` が `BepInEx/plugins` の下に1つだけあるか、`BepInEx/LogOutput.log` に読み込みエラーがないかを確認してください。 |
| カードを選べない・キャラが出ない | 女性キャラカードのPNGを選んだか、ファイルがまだ存在するかを確認してください。 |
| 「モデル『…』が見つかりません」 | モデル名が間違っているか、まだ導入されていません。「接続設定」の「一覧から選ぶ…」で選び直してください。 |
| 一覧を取得できない（HTTP 401） | APIキーが空か間違っています。キーを入れ直してから「一覧から選ぶ…」を押してください。 |
| 「接続失敗」／返事が来ない | OllamaまたはAPIサーバーが起動しているか、ブリッジURL・ポート・トークンを確認し、「ブリッジ再起動」のあと「接続確認」を押してください。 |
| 返事が途中で切れる・とても遅い | 思考するモデルを使っていないか確認してください。GPUをゲームと共有しているため、ゲームの起動中は生成が遅くなります。 |
| 服が思ったとおりに変わらない | 衣装によっては、半脱ぎなどの状態に対応していない部位があります。別の言い方で頼むか、小さいモデルなら大きいモデルに替えて試してください。 |
| 背景が出ない | 画像ファイルが移動・削除されていないか確認してください。まず「背景」でゲーム同梱の画像を選んで比べてください。 |
| 文字が見づらい | cfgの `JapaneseFontFile`、`InputFontSize`、`InputBackgroundOpacity` を調整し、ゲームを再起動してください。 |
| ブリッジの再起動が失敗する | 別のプログラムが同じポートを使っていないか確認してください。Modは無関係なプロセスを止めません。 |

ゲーム側のログは `BepInEx/LogOutput.log`、画面から再起動したブリッジのログは `BepInEx/config/amanatsu.ai-chat/bridge-logs` にあります。`[Conversation]` の行には、あなたの入力とキャラの返事を記録します。モデルの返事は `llm`、最初の挨拶は `llm-greeting` として区別します。ログには会話の内容や接続情報が含まれるので、人に渡す前に確認してください。

## 7. 更新・削除と確認済みの範囲

更新するときも、ゲームを終了してから新しい配布物の `install.ps1` を使ってください。削除するときは、ゲームを終了し、展開した配布フォルダーで `./uninstall.ps1 -GameRoot 'C:\ILLGAMES\AmanatsuLocation'` を実行します。Modのファイルだけを回収できる場所へ移し、設定・ログ・カード・セーブは残します。ブリッジが動いたままなら、必要に応じて別途終了してください。

OpenAIのAPI（GPT-6 luna）でも、日本語の会話と服装の頼みごとを実際のゲームで確かめました。この版で実際にゲームを動かして確認したのは、会話画面の表示、描画設定（ブルーム・被写界深度）の反映、表情・開き具合・ポーズ・ライト・メニューの開閉、衣装の切り替えと着脱状態の引き継ぎ、モデル一覧からの選択と接続確認、実際のモデルとの会話です。服装の頼み方は、ブリッジを通して代表的な言い方で確かめています。すべてのカード・衣装・解像度・他Modとの組み合わせは確認していません。ゲームやBepInExを更新したあとは、改めて動作を確認してください。
